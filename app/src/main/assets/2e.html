How to write wargear options

Start each option group with a line beginning with #, then the book's wording, then how it is chosen: one (pick one), any (pick any) or count (several models can take it). Optional extras, separated by |: each (cost is paid per model in the unit), cap:n5 (one per five models), cap:all-1 (every model except the sergeant), cap:2 (a fixed number), tag:Sgt (prefix in the exported list), ex:a,b (cannot combine with groups a and b), rq:t or rq:cons:Librarian (only shown once that group or option is chosen), po (the limit applies to each option separately), id:a (the group's id). In ex and rq, a group id followed by : and an option name refers to that single option. Then one line per option as Name | cost, optionally followed by | max:1 to limit that single option.
